# Returns and Promotions Policy

## Returns
Returns represent merchandise given back after purchase. Returns affect net sales and should not be treated as new positive sales.

When analysing return rates, numerator and denominator must use compatible definitions and time periods.

## Promotions
Promotions are commercial activities intended to influence purchase behaviour, including discounts and promotional campaigns.

A promotion can increase sales volume while reducing realized revenue per unit. Promotion performance should therefore not be evaluated using revenue alone.

## Recommended Analysis
A promotion analysis may combine sales revenue, units sold, discount amount, return amount, average selling price, and customer counts.

Numerical values must come from PostgreSQL. This document provides business interpretation.

## Agent Behaviour
If a user asks why revenue changed, use database results for the measured change and retrieve relevant business definitions from documents before explaining it.
